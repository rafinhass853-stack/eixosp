# Eixo SP — Gestão de Multas

Aplicação web para controle operacional de multas de trânsito de frota corporativa, com React, Vite, Tailwind CSS e Firebase.

> A implantação em produção depende de configurar as credenciais de implantação do Firebase Hosting e validar as regras do Firestore. Nenhuma base real é importada automaticamente.
